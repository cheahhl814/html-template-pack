html-template-pack

Three self-contained HTML templates — open any of them to interact with the live demo. No setup, no build step, no backend.

💡 What you can try in each demo
  • Theme toggle — click ◐ / ◑ top-right to switch themes
  • Density toggle — click ▤ / ▥ for compact spacing
  • Font size toggle — click S / M / L to scale text
  • Annotations (report + slide) — select text to leave notes
  • Tab switching (report) — click sidebar tabs to navigate
  • Slide nav — use ← → arrows or F for fullscreen
  • Print preview — Ctrl/Cmd+P for PDF output
  • Export — click 💬 Notes → 💾 Export to download JSON
📄

Report template

A long-form reading document with a sticky left sidebar of tabs. Reviewers click between tabs to read different sections, select text to leave tracked-changes-style notes, and export the notes as a JSON file when finished.

Single file. Sidebar collapses on narrow screens. Print hides sidebar and flows all sections with page breaks.

Live demo of html-template-pack — an agent skill (not a user-facing library) that auto-invokes when an AI coding agent is asked to build an HTML report, slide deck, or dashboard.

All three templates are self-contained HTML files. They work offline (after the first CDN fetch), print cleanly, and persist user state via localStorage.
