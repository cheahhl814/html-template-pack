html-template-pack

Three self-contained HTML templates — open any of them below in a new tab to interact with the live demo. No setup, no build step, no backend.

What you can try in each demo
  • Theme toggle — Click ◐ / ◑ (top-right) to switch themes. Reload to confirm it persists.
  • Density toggle — Click ▤ / ▥ to switch between comfortable and compact spacing.
  • Font size toggle — Click S / M / L to scale text.
  • Annotations (report + slide) — Select text to leave comment / delete / insert / replace notes. Click 💬 Notes to open the drawer. Export JSON via 💾 Export.
  • Tab switching (report) — Click sidebar tabs to navigate between sections.
  • Slide navigation (slide) — Use ← → arrow keys, dots, or F for fullscreen.
  • Print preview — Ctrl/Cmd+P to see how each template looks as a PDF.

About

This is a live demo of html-template-pack — an agent skill (not a user-facing library) that auto-invokes when an AI coding agent is asked to build an HTML report, slide deck, or dashboard.

All three templates are self-contained HTML files. They work offline (after the first CDN fetch), print cleanly, and persist user state via localStorage.
