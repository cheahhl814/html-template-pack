    Report Template

    Select any of this text and three pills appear — 💬 Comment, ✂ Delete, and ✎ Replace. Click one to leave a tracked-changes-style note (for delete/replace, optionally provide a comment explaining the change). For insertion, click the ➕ Insert button (top-right) then click any point in the text to drop a caret and propose new text. Your highlight is stored in this browser and reappears on reload. Open the 💬 Notes panel (top-right) to review, jump to, edit, delete, and export every annotation as JSON so an AI agent (or a colleague) can act on your feedback and revise this document precisely.

    How annotations anchor

    Each note stores the highlighted quote (or the caret position for inserts) plus its surrounding text and nearest heading, so it re-anchors even if the document is regenerated with minor changes. Diagrams and code (anything inside .mermaid, svg, or a data-annot-skip element) are ignored, so rendering them never shifts your highlights. Exported JSON carries the type (comment / delete / insert / replace) and a replacement field for structured edits — downstream revision agents don't need to parse free-text intent.
